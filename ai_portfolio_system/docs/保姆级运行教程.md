## 0. 这个项目是什么（30 秒看懂）

一个**多 Agent 的 AI 求职助手**，复刻了「RAG + SQL Agent + 简历/JD 匹配」的弹窗界面。它集成了：

- **RAG 检索增强** + **向量数据库**（默认 SQLite+numpy，可升级 Chroma）
- **Function Calling / SQL Agent**（带安全只读约束）
- **多 Agent 协作**：RAG 助手、SQL 分析、简历匹配、Evaluator（AI 检查 AI）
- **Self-Attention 微调迭代**：最多 3 轮，由评估器打分驱动优化
- **Codex 风格终端弹窗**（Textual 实现）

默认用 **Mock LLM**（假模型，离线可跑，用来验证管道），接真实大模型后才有真实内容。

## 3. 创建并激活虚拟环境（强烈建议，避免污染系统）

虚拟环境 = 一个独立的 Python 小房间，依赖只装在这里，不乱动你电脑上的其他东西。

### 3.1 创建（只需一次）
```bash
python -m venv .venv
```
执行完会多出一个 `.venv` 文件夹。

### 3.2 激活（每次打开新命令行都要做）
- **Windows（CMD / PowerShell）**：
  ```bash
  .venv\Scripts\activate
  ```
- **macOS / Linux**：
  ```bash
  source .venv/bin/activate
  ```

激活成功后，命令行前面会出现 `(.venv)` 字样，说明你在这个小房间里了。

> 如果 Windows 报"禁止运行脚本"，用管理员打开 PowerShell 执行：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，然后选 `Y`，再重新激活。

## 6. 运行项目（三种模式）

### 模式 A：Codex 风格终端弹窗（★ 推荐，最像参考图）
```bash
python -m src.main tui
```
会弹出一个深色终端窗口：
- 顶部标题栏：`AI Portfolio System`
- 中间聊天记录区
- 底部输入框

**怎么用弹窗**：
1. 在底部输入框里打字（例如：`帮我查一下 AI 岗位`）。
2. 按 **Enter** 发送。
3. 助手回复后会显示 `评分` 和 `迭代次数`（Self-Attention 迭代）。
4. 退出：按 **Ctrl+C** 或 **Ctrl+Q**。

弹窗效果截图见 `data/tui_screenshot.svg`。

### 模式 B：纯命令行交互（更简单，适合没图形界面）
```bash
python -m src.main chat
```
进入后会出现 `>` 提示符，直接打字提问。内置命令：
- `/agent` —— 列出所有 Agent（rag / sql / match / evaluator）
- `/model` —— 显示当前使用的模型
- `/quit` 或 `/exit` —— 退出

示例会话：
```
> 查询所有 AI 岗位
[sql] 评分: 0.0  迭代: 3
SELECT title, company, location FROM jobs WHERE category = 'AI' LIMIT 5;
...

> /quit
```

### 模式 C：查看当前配置
```bash
python -m src.main info
```
输出当前 LLM provider、嵌入模型、向量库路径。

## 8. 接真实大模型（想看到真内容才需要做）

默认是 Mock，要真内容二选一：

### 方案 1：OpenAI（最简单）
1. 拿到 API Key：https://platform.openai.com/api-keys
2. 设置环境变量（命令行执行，**每次新开窗口都要设**）：
   - Windows（CMD）：
     ```bash
     set OPENAI_API_KEY=你的key
     ```
   - Windows（PowerShell）：
     ```powershell
     $env:OPENAI_API_KEY="你的key"
     ```
   - macOS / Linux：
     ```bash
     export OPENAI_API_KEY=你的key
     ```
3. 改 `config.yaml` 第 4 行：
   ```yaml
   llm:
     provider: openai   # 把 mock 改成 openai
   ```
4. 装 LLM 支持（如果没装完整依赖）：
   ```bash
   pip install langchain-openai
   ```
5. 重新运行 `python -m src.main tui`，现在就是真模型了。

### 方案 2：Ollama 本地模型（免费、数据不出本机，推荐）
1. 安装 Ollama：https://ollama.com/download ，装完它会自动后台运行。
2. 拉取模型（命令行）：
   ```bash
   ollama pull qwen2.5
   ```
3. 确认服务在 `http://localhost:11434`（默认就是）。
4. 改 `config.yaml`：
   ```yaml
   llm:
     provider: ollama   # 把 mock 改成 ollama
   ```
   （`ollama.model` 默认已是 `qwen2.5`，不用改）
5. 重新运行 `python -m src.main tui`。

## 9. 升级语义检索（可选进阶）

默认用 **TF-IDF 关键词嵌入 + SQLite 向量库**（轻量、够用）。想要更接近生产级的语义检索：

1. 装完整依赖（见 4.2）或单独装：
   ```bash
   pip install chromadb sentence-transformers
   ```
2. 改 `config.yaml` 让向量库指向 Chroma（默认已经是，只是之前没装包所以回退了）：
   ```yaml
   retrieval:
     vector:
       persist_dir: ./data/chroma
   embeddings:
     model: sentence-transformers/all-MiniLM-L6-v2
   ```
3. 重新 `python -m src.scripts.ingest` 重建索引。
4. 再跑 `python -m src.main tui`，检索质量会更好。

## 10. 常见问题排错（FAQ）

**Q1：运行 `python -m src.main tui` 报 `No module named src`？**
→ 你没在 `ai_portfolio_system/` 目录下执行。先 `cd` 进项目目录（见第 2 步），且确认已激活虚拟环境（见第 3 步）。

**Q2：运行报 `textual` 相关错误 / 弹窗乱码？**
→ 没装依赖。回到第 4 步 `pip install -r requirements.txt`。如果已装，确认激活了正确的 `(.venv)` 环境。

**Q3：RAG 回答总是"未找到资料"？**
→ 先跑 `python -m src.scripts.ingest` 灌数据；检查 `data/chroma` 或向量库是否生成。

**Q4：评分一直是 0.0 / 内容是占位文字？**
→ 这是 **Mock LLM 的正常行为**（见第 7 步）。想看真内容按第 8 步接真实模型。

**Q5：WARNING：sentence-transformers not installed / web search disabled？**
→ 正常的降级提示。前者表示在用 TF-IDF 回退，后者表示 Web 检索未启用。都不影响运行。想消除前者就按第 9 步装完整依赖；想启用 Web 检索就 `pip install duckduckgo-search` 并确保 `config.yaml` 里 `retrieval.web.enabled: true`。

**Q6：想清空数据重来？**
```bash
rm -rf data/chroma data/*.db    # Windows 也可用资源管理器手动删 data/chroma 和 data/*.db
python -m src.scripts.ingest
```

**Q7：运行 `python -m src.scripts.ingest` 或 `tui` 报 `No module named 'numpy'`？**
→ 这是项目早期 `requirements.txt` 漏写 `numpy` 和 `scikit-learn` 导致的，已在当前版本修正。先执行：
```bash
pip install numpy scikit-learn
```
然后重新跑 `python -m src.scripts.ingest` 即可。如果以后用新 clone 的代码，直接 `pip install -r requirements.txt` 就不会再缺。
